# 얼굴 파싱 모델

여기에 `face-parsing.onnx`를 두면 기하 측정이 켜진다. 없으면 8필드를 모두 LLM 관찰로 채운다
(파일이 없다고 기동이 실패하지는 않는다).

경로는 `MOPICK_FACE_PARSING_MODEL`로 바꿀 수 있다.

## 요구 사항

- 출력이 **CelebAMask-HQ 19분류** 체계여야 한다. `FaceParsingMask`가 그 번호를 전제로 한다.
  특히 hair(17), l_ear(7), r_ear(8), skin(1), neck(14), cloth(16)을 쓴다.
- 입력 512×512, NCHW float32, ImageNet 정규화(mean 0.485/0.456/0.406, std 0.229/0.224/0.225).
- 출력 `[1][클래스][512][512]` 로짓.

분류 체계가 다른 모델을 쓰려면 `FaceParsingMask`의 상수를 그 모델 기준으로 바꾸면 된다.

## 라이선스 주의

CelebAMask-HQ로 학습한 가중치는 **비상업 연구용**으로 배포되는 경우가 많다.
서비스를 상업적으로 운영할 계획이라면 반드시 해당 가중치의 라이선스를 확인하고,
필요하면 상업 이용이 가능한 데이터로 학습된 모델로 교체해야 한다.

이 디렉터리의 모델 파일은 .gitignore 대상이다.
